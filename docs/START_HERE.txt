SMART CAMPUS - HOW TO OPEN THE WEBSITE

1. Extract the complete ZIP folder.
2. Install Node.js version 22.5 or newer: https://nodejs.org/
3. Double-click start.bat (Windows).
4. Wait until the terminal says: Smart Campus AI running at http://localhost:3000
5. Open this address in Chrome: http://localhost:3000
6. Keep the black terminal window open while using the site.
